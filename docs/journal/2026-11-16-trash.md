# The Trash, and drag and drop

## What was asked

> that's correct, deleted files go to trash, trash currently does not work.
> It should open a file browser, even if empty. You can drag files to the
> open explorer or the desktop icon to move the mto the trash can.
>
> The trash can explorer has an option in the navigation bar to permanently
> delete the files in it

## What was found

- Delete in the File manager removed files for good after a question. The
  Recycle Bin icon said "not available yet".
- The window manager had no drag and drop of anything but windows (moving
  and resizing with an XOR outline).

## Options considered

- Where the Trash lives: a hidden folder on C: (`C:\.trash`) against a
  folder per drive. One folder on C: was chosen; other drives delete for
  good, and the question says so.
- Remembering where each item came from: an index file
  (`C:\.config\trash.ini`) so Restore can put it back, cheap enough to do.
- "Navigation bar": the first build had Empty Trash only in the File menu;
  the owner's wording meant the toolbar, so a button was added there too.

## What was chosen and why

- Delete asks "move ... to the Trash?" and moves the file or folder (whole) to
  `C:\.trash`, numbered on a name clash. Dragging onto the Trash does not
  ask. Delete inside the Trash and Empty Trash remove for good after asking
  (Empty Trash says how many). Restore puts an item back, numbered if the
  name is taken, its folder made again if gone.
- The Trash window: the File manager's icon view on `C:\.trash`, with
  Restore, Delete, Empty Trash; an Empty Trash button in its toolbar, greyed
  out when empty; the status bar says where the chosen item came from.
- Drag and drop in the window manager: `Wm::begin_drag()` from a widget or a
  desktop icon, a 32 px outline following the pointer, drop targets
  highlighted (desktop icons with a drop function, windows that accept in
  `drag_over()`). Files can also be dragged onto folders (same drive), onto
  the empty desktop (into `C:\Documents\Desktop`), and Escape cancels.
- The icon shows paper in an open bin when the Trash holds anything; a 16 x 16
  bin was drawn for the toolbar and title bar (the 32 px one shrunk was
  invisible on grey). All own art.
- The desktop icon is now called "Trash" (provisional).

## What was built and tested

`core/src/shell/trash.cpp`, the Trash window in
`core/src/shell/file_manager.cpp`, drag and drop in `core/src/wm/wm.cpp`.
PC tests in `host/tests/render_scenes.cpp`: delete to the Trash, Restore, a
second file of the same name numbered, drops onto the icon, the window and a
folder, the Empty Trash button, Escape, the drop on the desktop, with
reference pictures. On the board: a desktop file dragged onto the icon and
onto the window, Restore, Empty Trash from the menu and from the button.

## What was learned

`tools/dbg.py mouse move` releases the button unless told `--buttons left`;
the first board drag "did nothing" for that reason.
