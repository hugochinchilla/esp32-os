# Icons: the inventory, the taskbar and the folder toolbar

2026-11-16. PC only; nothing here has run on the board yet.

## What was asked

The owner, while the more technical work went on in other threads:

> Me gustaría que hicieras una revisión de la iconografía de todos los
> procesos, programas, y necesitarán tener pues como un icono grande, como si
> tuvieran un acceso directo en el escritorio, un icono pequeño como el que se
> ve en la lista de programas del menú de inicio, y no sé si hay una versión
> incluso más pequeña, que es la que se está utilizando en la barra de título
> de las ventanas y en el Task Manager. [...] en especial, no me gusta nada el
> del editor de texto. [...] junto al menú de inicio en la barra de tareas.
> Hay unos iconos que no hacen nada, vamos a quitarlos, ya los añadiremos
> cuando funcionen. Y revisemos también la iconografía del explorador de
> archivos, la barra superior [...] las navegaciones de arriba y atrás, que
> comparten icono. Vamos a crear iconos diferentes para ello.

Four parts: an inventory, proposals for refined icons (his to choose), the
dead taskbar icons out, and separate icons for Back and Up. This entry covers
the inventory and the two clear changes. The proposals get their own entry
when he has chosen.

## What was found

### Sizes

There are two sizes and no third one: 32x32 and 16x16. All of them are text
rows in `core/src/gfx/art.cpp` (Cactus Patch keeps its own in
`core/src/shell/cactus_patch.cpp`), turned into pixels by the compiler.

| Where | Size |
| --- | --- |
| Desktop icons, File manager icon view | 32x32 |
| Start menu and its submenus | 16x16 |
| Window title bar | 16x16 |
| Taskbar window buttons | 16x16 (the window's own) |
| Task Manager list | 16x16 (the window's own; the settings icon for a process with no window) |
| File manager toolbar and address bar | 16x16 |
| Tray (Wi-Fi signal) | 16x16 |
| About, Shut Down | the 16x16 mascot drawn at double size |

So the title bar and the Task Manager do not use a smaller icon: they use the
Start menu one.

### Processes without a window

`desktop`, `netd`, `vncd`, `httpd`, `dbgd`. In the Task Manager's list of all
processes each shows the control-panel icon. None has a picture of its own.

### Things that are not programs

My Board (32x32 only; its window shows the folder), drive (both), folder
(both), text file (both), picture file (both), any other file (32x32 only),
Settings (16x16 only), the Wi-Fi signal (11 pictures of 16x16: 0 to 4 bars,
with and without padlock, and the red cross).

### The taskbar

Three 16x16 pictures stood between the Start button and the window buttons
(folder, text page, network), from the target picture of the 98 look. The
code said of them "they do nothing yet", and `docs/DECISIONS.md` listed it as
a known difference. A click on them did nothing.

The Wi-Fi signal icon at the other end, by the clock, does work: a click
opens the Network panel, and it shows the bars or a red cross (seen on the
board on main the same day). It appears only on a machine with Wi-Fi.

### The folder toolbar

Back and Up in the File manager (`core/src/shell/file_manager.cpp`) both drew
`folder_icon_16()`, the same picture as the window's title bar and the address
bar: four folders in the top 60 pixels of the window.

## Options considered

**The space the quick-launch icons leave.**

1. Close it: the window buttons move left, to where the icons were, with one
   groove after Start. Cost: every reference picture with a taskbar changes.
2. Leave the gap empty between its two grooves. No picture of a window button
   moves, but an empty box on the taskbar looks like something is broken.
3. Keep the icons and wire them now (File manager, Editor, Network). Not what
   was asked, and which programs go there is the owner's choice.

**Back and Up.** A plain arrow for each (left, up) was the cheapest, but two
arrows that differ only in direction say little. Up as a folder with an arrow
says "the folder above"; Back as an arrow alone says "where I was".

## What was chosen

- Option 1 for the taskbar, by the agent, as the plain reading of "vamos a
  quitarlos": the bar shows only what works. Not 2, because of the empty box;
  not 3, because the owner said they come back later.
- The Wi-Fi icon stays, because it works.
- Back: a blue arrow pointing left, lighter on its upper edge. Up: the small
  folder with a green arrow rising out of it. Both original, drawn here.
  These two may still change with the icon proposals.

## What was built

- `core/src/gfx/art.cpp`, `art.hpp`: `back_icon_16()`, `up_icon_16()`.
- `core/src/shell/file_manager.cpp`: the two toolbar buttons use them.
- `core/src/wm/wm.cpp`: the three pictures and one of the two grooves are
  gone; the first window button is at x = 72 (was 144), so the buttons have
  72 pixels more before they start to shrink.
- 84 reference pictures in `host/tests/pictures/` rewritten, since nearly all
  show the taskbar. Looked at: the taskbar, and the folder toolbar.

Tested: the PC tests, 22 of 22. The firmware was not compiled for this change
and it has not run on the board. No firmware file changed: all of it is in
`core/`.
